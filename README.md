# Life Compass

An open-source, browser-only space to explore personal values. Built with Vite, vanilla TypeScript, HTML, and CSS. No backend, authentication, analytics, or external APIs.

## Run locally

```sh
npm install
npm run dev
```

## Contributing

Small, focused contributions are welcome. Keep the app framework-free, preserve the values data, and run `npm run check` and `npm run build` before submitting changes.
